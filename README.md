# Sistem Inventaris Barang (PHP + MySQL)

## Cara menjalankan
1. Install XAMPP, jalankan Apache + MySQL.
2. Salin folder `inventaris` ke `C:\xampp\htdocs\`.
3. Buka http://localhost/phpmyadmin -> tab Import -> pilih `database.sql` -> Go.
4. Buka http://localhost/inventaris/login.php
5. Login: admin / admin123
